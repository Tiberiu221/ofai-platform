Securitate & Rate Limiting
Masuri de Securitate
  • CSRF — double-submit cookie (csrf-csrf)
  • Helmet.js — security headers (CORP disabled for CDN)
  • bcrypt — password hashing (cost factor 10)
  • JWT rotation — refresh token rotativ, DB-backed
  • Input validation — server-side sanitization
  • SQL parameterization — $1, $2 placeholders
  • 7 audituri de securitate (113+ issues found & fixed)
Rate Limiters (9)
  • general 100 req/min — global middleware
  • auth 10 req/15min — login, register
  • passwordReset 3 req/h — forgot password
  • verifyCode 5 req/15min — reset code
  • admin 60 req/min — admin panel
  • createContent 20 req/h — reviews
  • click 100 req/min — analytics
  • search 30 req/min — autocomplete
  • reveal 20 req/min — promo codes
Probleme Cunoscute & Limitari
Rate limiter persistence — in-memory, se reseteaza la deploy. Necesita Redis/PG store.

Firebase keys in git history — cheile au fost rotite, dar history-ul contine versiunile vechi.

Gallery race condition — count check non-atomic; upload-uri concurente pot depasi limita de 8.

Feed format mismatch — backend returneaza array plain, Flutter asteapta PaginatedResponse.

Gamification dedup — follow/unfollow toggling poate genera puncte infinite (fara dedup).

Streak timezone — UTC vs Romania UTC+2/3 poate intrerupe streak-urile la ora 23:00 local.
Deployment — git push origin main declanseaza auto-deploy pe Railway (~1-2 min). Migratiile SQL se ruleaza separat via run-migration-production.js. DNS gestionat prin Cloudflare (CNAME proxy ON). Flutter SDK la C:\dev\flutter.
